Ayarlar & Kurulum

🔑 API Anahtarı
⚠️ Anahtar sessionStorage'da saklanır — sekme kapanınca silinir. Public bilgisayarlarda kullanmayın. HTML dosyasına hardcode etmeyin.
console.anthropic.com'dan alabilirsiniz.
🚀 GitHub Pages Kurulumu
  1. Bu sayfayı Ctrl+S ile index.html olarak kaydedin
  2. GitHub'da public yeni repository oluşturun (örn. odusobiad-editor)
  3. index.html'i main branch'e yükleyin
  4. Settings → Pages → Source: main / root
  5. ~2 dakika sonra https://[kullanıcıadı].github.io/odusobiad-editor aktif

Her oturumda API anahtarınızı girin. Mammoth.js CDN gerektirir — internet bağlantısı olmalıdır.
